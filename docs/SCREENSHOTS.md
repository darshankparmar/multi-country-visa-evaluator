# 📸 Application Screenshots

This document showcases the key features and user interface of the Multi-Country Visa Evaluator application.

![Home Page](images/home_page.png)

## 📝 Multi-Step Evaluation Form

### Step 1: Personal Information
Users enter their basic information including name and email address.

![Evaluation Form - Step 1](images/multi_step_evaluation_form_1.png)

### Step 2: Country & Visa Type Selection
Users select their target country and desired visa type from available options.

![Evaluation Form - Step 2](images/multi_step_evaluation_form_2.png)

### Step 3: Document Upload
Users upload required documents based on the selected visa type (PDF, DOCX supported).

![Evaluation Form - Step 3](images/multi_step_evaluation_form_3.png)

### Step 4: Review & Submit
Users review their information before final submission.

![Evaluation Form - Step 4](images/multi_step_evaluation_form_4.png)

---

## ✅ Evaluation Result Page

After submission, users receive a comprehensive evaluation with:
- Overall score (0-100)
- Approval likelihood assessment
- Detailed criteria analysis with ratings
- Prioritized recommendations
- Score breakdown by category

![Evaluation Result](images/evaluation_result_page.png)

## 📊 Partner Dashboard

The partner dashboard provides comprehensive analytics including:
- Total evaluations count
- Average score metrics
- Evaluations by country (bar chart)
- Evaluations by visa type (bar chart)
- Evaluation trends over time (line chart)
- Detailed evaluation list with filters
- CSV export functionality
